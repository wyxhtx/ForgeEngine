# ForgeEngine 概念速查（AI 术语解释命中用）

> 每条：一句话定义 → 机制 → 项目里的对应。按字母/主题排列。

## 构建与依赖

- **manifest 模式**：项目根放 vcpkg.json，CMake toolchain 自动识别并按清单装依赖。
  项目：vcpkg.json 13 依赖直列 → 装到 build\vcpkg_installed（含间接共 29 包）。
- **builtin-baseline**：vcpkg 官方仓库某 commit，锁"官方库版本表"。
  项目：61d43ee...；官方直用 8 库版本由它定；覆盖官方 3（ktx/tinygltf/freetype）按 overlay 内版本。
- **overlay port**：config\vcpkg\port 下的端口优先于官方同名端口。
  项目：9 端口 = 6 纯自定义 + 3 覆盖官方（ktx 7z解压、tinygltf 修SHA512、freetype 补丁集）；另有纯自定义 msdf-atlas-gen（upstream 无，外链官方 msdfgen）。
- **REF 锁 commit**：vcpkg_from_git 用 commit SHA 钉死源码版本（内容不可变，可复现）。
  项目：6 纯自定义库各自 portfile 的 REF=40位SHA；FETCH_REF 才用 branch/tag。
- **triplet**：vcpkg 编译库的规格文件（架构/CRT/库链接/宏）。
  项目：x64-windows-static-forgeengine.cmake（全静态 + Debug IDL=1）。
- **CMAKE_CONFIGURATION_TYPES**：VS 多配置生成器的配置集合。
  项目："Debug;Release;RelWithDebInfo"——RelWithDebInfo 重定义为快速日常档（/Od /Zi /DNDEBUG，编译快、带 PDB 可断点、无 STL 检查）；勿自定义新配置名（vcpkg 只认内置名）。
- **PCH（预编译头）**：把稳定头先编成 .pch，各 TU 复用，省重复解析。
  项目：target_precompile_headers(External.h)——系统+三方稳定头；带 *_IMPLEMENTATION 的头不能进 PCH（VMA/tinygltf 留在 Main.h 单 TU include）。
- **CMakePresets.json 必须严格 JSON**：不支持注释（实测报错）——说明只能写文档。
- **CMakeCache.txt**：配置期固化的变量+路径；改目录/换 preset 后旧 cache 会失效（fe-clean 重建）。

- **工具链（生成器 / 工具集）**：CMake「生成器」决定用哪代 VS 的 MSBuild（`Visual Studio 18 2026`），「工具集」决定用哪版 MSVC 编译器（v145 = 14.51）。
  项目：VS2026 18.10 + 生成器 `Visual Studio 18 2026` + 工具集 v145；vcpkg 侧用 `VCPKG_PLATFORM_TOOLSET=v145` 对齐；**exe 与依赖库必须同工具链**（否则 LNK2019 `__std_unique_4`）。

## 库类型

- **header-only**：库全在头文件，include 即用、无 .lib 链接。
  项目：glm/VMA/tinygltf/kmeans/stb/aarand/subpar/sanisizer（INTERFACE 目标）。
- **静态库 vs 导入库**：静态 .lib 含实现（MT 全静态）；导入库只是 dll 的跳板。
  项目：glfw/ktx/freetype/msdfgen/msdf-atlas-gen/FastNoise2 等=静态；Vulkan::Vulkan=导入库（背后 vulkan-1.dll 系统级）。
- **find_package vs find_path**：前者吃官方/自产 config；后者手动找头文件（端口无 config 时）。
  项目：官方与自产 CONFIG 全走 find_package（含 msdfgen/msdf-atlas-gen）；tinygltf/kmeans 无 config → find_path 封装；fastnoise2 → find_path+find_library。
- **INTERFACE vs IMPORTED**：INTERFACE=封装头文件目录（自产）；IMPORTED=指向外部已编库（ForgeFastNoise 连 .lib+宏）。
- **MSVC 运行库 MT/MTd**：/MT 静态 Release、/MTd 静态 Debug——项目全静态，与 vcpkg 静态库一致。
- **MSDF（多通道有符号距离场）**：每字形存 4 通道距离场，缩放渲染边缘不糊。
  项目：UI 文本栈 = freetype 读轮廓 → msdfgen 距离场 → msdf-atlas-gen 打包 RGBA8 图集（generateMsdfAtlas，字集＝ASCII ＋ 资产字集表 3500 汉字，emSize32）；字形表 glyphMap：codepoint→msdfGlyphNode(advance/uv)；forgeengine-stb-font 位图字库已删（P2 移除）。

## 编译与源码

- **单 TU（翻译单元）**：Main.cpp include 全部实现 → 1 个 TU 编译（故 /bigobj）。
  项目：Main.cpp → Main.h（头内实现 + VMA/tinygltf IMPLEMENTATION）→ External.h（PCH 三方稳定头）。
- **GLOB / CONFIGURE_DEPENDS**：通配符收集文件；CONFIGURE_DEPENDS=构建时自动检测文件增删。
  项目：源码/资产/文档显示分组全用 GLOB（纯显示不编译）。
- **source_group**：给 target 文件分组，让 VS 按组/磁盘目录显示。
  项目：src\code(TREE)、config、docs(含chatbox-docs)、cmd、assets。
- **add_custom_command / .rule / CMake Rules**：自定义命令（编 spv）→ 生成 .rule 给 MSBuild 执行；
  VS 对含规则输出的 target 显示 "CMake Rules" 节点（正常现象）。
- **_ITERATOR_DEBUG_LEVEL / LNK2038**：STL 迭代器检查级别（0/1/2）；
  项目 exe(Main.h) 与 vcpkg 库(triplet) Debug 都=1，一致则无 LNK2038。
- **生成器表达式 $<CONFIG:Debug>**：按配置展开（选 Debug 库/宏）。
  项目：ForgeFastNoise Debug 链 FastNoiseD.lib、MSVC_RUNTIME_LIBRARY MT/MTd。

## 资产与命名

- **spv 命名**：shader_src\xxx.vert → shader\xxxVert.spv；.frag → xxxFrag.spv（管线内同名）。
- **fe- 前缀**：fe = ForgeEngine；fe-xxx = 调试指令（fe-st = git status 等 15 个）。
- **引擎 vs 游戏**：ForgeEngine=引擎（工程/exe/脚本）；Forge=游戏（src\code\forge、gameName 互斥名）。

## 数据层模块化流程：enum → info → struct → list（2026-10-02 定稿）
四件套各司其职、**单向依赖**（后者可用前者，前者不引用后者）：

| 层 | 文件 | 放什么 | 命名与形态 |
|---|---|---|---|
| ① enum | `src\code\vk\data\VkEnum.h` | 全部枚举（类型/维度/表项） | 按域分命名空间：`engineEnum` / `uiEnum` / `renderEnum` / `descEnum` / `samplerEnum` / `vertexEnum` / `pipelineEnum` / `bufferEnum`；叶子名用 `xxxId`（维度或表项）；末尾 `enumCount`（枚举长度） |
| ② info | `src\code\vk\data\VkInfo.h` | 常量/开关/路径/尺寸（**只读配置，不放状态**） | 命名空间：`debugInfo`（开关）/ `engineInfo`（缓存开关、设备扩展）/ `fileInfo`（路径）/ `textureInfo`（尺寸格式）/ `pipelineInfo`（管线常量） |
| ③ struct | `src\code\vk\data\VkStruct.h` | 结点：**数据 + 行为** | `namespace xxxStruct { struct xxxNode { … } }`；行为用 `create*` / `clear` / `check*`；配置类成对出现：`xxxConfigParamNode`（预设传参）＋ `xxxConfigNode`（结果） |
| ④ list | `src\code\vk\data\VkList.h` | 运行期集合：**创建/持有/清理** | `proc*Node`（`procSamplerNode` / `procPipelineNode` …），内部 `std::vector<③的Node>`，容量按 `①::enumCount` 定长；负责一次性建全（`createXxxList`）与释放（`clear`） |

**流向**：`① 定义类型 → ② 取常量 → ③ 把类型与常量组装成结点 → ④ 把结点装进集合并按枚举定长/登记`。

### 新增一个「可配项」的固定流程（采样器已按此落地并验证）
1. **enum**：立维度枚举 `xxxId`（末尾 `enumCount //枚举长度`）；若该维度需要「未指定」语义，再加 `enumNull //枚举空值`（放 `enumCount` 之后、取值 n+1、**无尾逗号**）；若它本身就是「无/不启用」的**语义值**，用 `none`（放首位、值 0）。
2. **info**：需要常量/开关/路径就加到对应命名空间（如缓存开关、缓存路径）。
3. **struct**：加参数结点字段（每维度一字段＋默认值）＋结果结点，并写**逐维度映射** `createXxx(预设)`（`switch` + `default` 打「未写预设处理」）。
4. **list**：加**登记表**一行（只写与默认不同的维度，如 `{ .magType = nearest, .lodSourceType = runtime, .maxLod = … }`）＋自检（表长 == `enumCount`）＋创建/清理。
5. **验证**：临时打印「实际提交给驱动的生效配置」与旧实现手推表逐项对账 ＋ 构建 0 错 0 警；撤销临时打印后重建。

### 两条硬规矩（都是踩坑换来的）
- **数据填充不得挂在日志/调试开关之下**：否则关日志＝关数据（曾致 `limits` 全 0 ⇒ `maxAnisotropy=0` 喂给驱动 ⇒ 崩在驱动 DLL 且没有任何自己的报错）。只把**打印**放开关里，数据无条件执行；关键合法性自检也**不挂** dev 开关。
- **开关判据用 `FORGE_DEV_BUILD`**（CMake generator expression，只 Debug/RelWithDebInfo 定义 ⇒ **只有 Release 关**校验层与日志）；**不要用 `NDEBUG`**（本仓库 RelWithDebInfo 带 `/DNDEBUG`，会把日常档一起关掉）。
