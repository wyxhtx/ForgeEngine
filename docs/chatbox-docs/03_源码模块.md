# ForgeEngine 源码模块导航（src\code）

> 用途：改 vk/forge 代码前先读（数据流级）。文件清单以仓库实际为准。

## 顶层布局

    src\code\vk\    = Vulkan 渲染层（窗口/设备/管线/资源）
    src\code\forge\ = 世界层（Debug/Loop 驱动 + Plate/Chunk/Storage 世界）
    单 TU：Main.cpp → Main.h（头内实现 + VMA/tinygltf IMPLEMENTATION）→ External.h（PCH 三方稳定头）

## 数据流

① 世界生成：FastNoise → Chunk(32³+边缘34) → 链结构(linkStructManager ≤32 无空气) → 贪心合并/面剔除 → terrainVertex → Buffer → 双管线(Layer_0 视距4 / Layer_1 视距8)；kmeans 分区 + std::transform(par) 并行

② 渲染帧：acquire → 记录命令缓冲（transientCmd 池）→ 各管线（shadow/dsScence/osScence/osMirror/skybox/terrain/mine/uiText）→ present

③ 原点迁移：double 坐标 + originShiftThreshold=256 → 平移重定位（防 float 抖动）

④ 存储：full/delta 双法 → thresholdSize 切换 → region 3x3x3（边长32）→ storage\chunk\（忽略）

⑤ 线程锁（lockInfo）：queueThreadLock/logThreadLock/musicThreadLock/plateMeshDataLock/chunkMapDataLock/drawFuncLock + 原子 getLock(compare_exchange_strong)

⑥ 地形：当前走 vert+frag（terrainDeferred.vert/.frag）；MeshShader 路子（createMeshPipelineNode + terrainDeferredTask/Mesh.spv）代码里已留位但未启用——VkList.h 那行 mesh 管线创建是注释、两个 spv 不存在。数据源 terrainVertex，与其余管线共用同一套顶点格式

⑦ 文本（MSDF）：freetype 读轮廓 → msdfgen 距离场 → msdf-atlas-gen 打包 RGBA8 图集 → glyphMap(codepoint→msdfGlyphNode) → Buffer drawUIText 定宽布局（P2 重构，ASCII 字集）

## 精度常量

noiseExtreme=2^23（FastNoise 极值）· sightRange=8 · groundPlane=4096 · originShift=256 · Chunk 32 · cubeArray 34
