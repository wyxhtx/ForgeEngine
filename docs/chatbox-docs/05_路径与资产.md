# ForgeEngine 路径与资产约定

> 用途：资源加载路径/目录状态/运行约定。基于 VkInfo.h fileInfo 实测 + 目录树核对。

## 根路径与构建产物位

    E:\code\graphicsAPI\vulkan\ForgeEngine    项目根（F5 工作目录=根，资源用相对路径 src\assets\...）
    build\vs\bin\output\x64\{Debug,Release}\ForgeEngine.exe    exe/pdb（RelWithDebInfo 同目录）
    build\vs\bin\output\x64\{Debug,Release}\src\assets\...     运行时资源副本（构建时自动复制，镜像 src\assets 相对路径）
    build\vs\bin\intermediate\x64\{cfg}\                        引擎中间产物（obj/tlog/pch，Directory.Build.targets 覆盖 IntDir）
    build\vs\bin\intermediate\x64\{cfg}\{辅助工程}\              辅助工程（ForgeShader 等）的输出与中间产物
    build\vcpkg_installed\                       依赖安装（x64-windows-static-forgeengine\）
    config\tool\                                 构建期辅助工具源码（引擎的小工具统一放这；接线规则在 config\cmake\）
    config\cmake\                                CMake 模块（ForgeShader / 中间目录覆盖）

## 临时/备份件约定（唯一落点 build\temp\）

    build\temp\bak\      改动前备份（<文件名>.<用途>.bak）
    build\temp\log\      校验输出 / 批量报告（*.txt、*.md）
    build\temp\probe\    原型脚本与试验件（改原型不动正式件）
    build\temp\work\     解包 / 逐文件比对用的中间工作目录

1. 一律落 `build\temp\`，**不散落到 `build\` 顶层、不放仓库根、不放 src\ / docs\**
2. `build\*` 已被 .gitignore 忽略（仅放行 `build\ForgeEngine.slnx`）→ temp 里不产生 git 噪音
3. `fe-clean` 只删 `build\vs\`，不会误删 temp
4. 清理由用户发话统一做，**不做静默删除**
5. 需长期保留的成果放 `docs\`（git 跟踪），不进 temp

## storage 与运行数据

    storage\chunk\full|delta\*.dat   运行时区块存档（.gitignore 忽略；删了会重新生成）

## 路径相关注意

1. 资源路径全部相对项目根（F5 工作目录已设为根），**代码里勿写绝对路径**
2. spv 缺失时运行会报"找不到"——先 fe-br 确保 shader\ 生成齐全
3. 新增 spv 管线时：ForgeShader.cmake 规则 + VkInfo.h fileInfo 变量 **两处命名必须一致**（大小写也要一致——Windows 不敏感能跑，换大小写敏感的文件系统就崩；历史上 uiText→uitext 就这么埋过一颗）
4. image_src 改图流程：改 png/jpeg → 跑 png_to_ktx2.bat → 得到 image\ 新 ktx2
5. assets 全目录 GLOB 自动显示于解决方案工程树；新增文件/文件夹无需改 CMake（font\ 同理）
6. 输出目录的 `src\assets` 由构建 POST_BUILD 自动复制（shader/image/model/music/font 五个子目录）→ 从输出目录运行/双击 exe 同样能找到资源；改完资源 fe-build 即同步
7. 资源清单核对会有 **3 条"缺失"是既有死条目**，不是漏复制：`terrainDeferredTask.spv` / `terrainDeferredMesh.spv`（`VkList.h` 里 MeshShader 建管线那行已注释，当前地形走 vert+frag 经典管线）、`model/nextTemp/scene.gltf` 与 `src/music/background/Greedy.wav`（VkInfo.h 里本就是注释行）
