5 · 命名与排版规范（这次的返工就是缺这条）

项规范
项名全小写 snake_case（fill_back_ccw），与 Vk 常量的 SCREAMING_CASE 一眼区分；不要混用 camelCase（现文件里两种混着 ✗）
枚举类型名xxxId；末尾固定 count（表尺寸）；static_assert(count == N) 防漂移
注释列三列：名字 │ 功能 │ 说明；列间 Tab 顶到统一目标列，列内文本用单个空格；行尾不得有空白
列边界作者写 Tab 的地方才是列边界；工具不得新造列、不得压缩注释文本（align-comments-v17.ps1 已按此加固）
对齐工具cmd\align-comments-v17.ps1 -Recurse -Preview 20 先看，再 -Apply；默认只作用 src\code\vk\data
编码UTF-8 无 BOM / CRLF / 无尾换行；.ps1 必须带 BOM
谁来排生成脚本负责初版排版，此后手改只改内容；改完跑一次"幂等自检"（再跑 0 改动）
