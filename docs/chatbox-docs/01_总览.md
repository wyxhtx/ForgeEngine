# ForgeEngine 总览

> AI 协作知识库入口（docs\chatbox-docs\）。用途：让 AI 快速了解项目全貌后进入任务。
> 阅读顺序：本文件 → 按任务查 02-08（07=AI 工作手册，08=工作流）。

## 一句话定位

ForgeEngine 是无限体素世界 3D 沙盒游戏引擎（C++20 + Vulkan）。
命名：**ForgeEngine = 引擎**（工程/exe/脚本前缀 fe-）；**Forge = 引擎下的游戏**（游戏层 src\code\forge、进程互斥名）。

## 技术栈

| 领域 | 选型 | 要点 |
|---|---|---|
| 语言 | C++20 MSVC | 单 TU：Main.cpp → Main.h（头内实现）+ External.h（PCH 三方稳定头） |
| 图形 | Vulkan 1.4 | VK_EXT_MESH_SHADER + VK_KHR_swapchain |
| 依赖 | vcpkg manifest | vcpkg.json 13 依赖直列 + config\vcpkg\ overlay（triplet + 9 端口） |
| 构建 | CMake | 配置三档 Debug/Release/RelWithDebInfo（RelWithDebInfo=快速日常档）；vs/ninja 预设 |
| 库 | GLFW/glm/tinygltf/KTX2/FastNoise2/OpenAL+ALUT + MSDF 文本栈(msdfgen/msdf-atlas-gen/freetype) | 全静态链接 |

## 目录（一级）

    ForgeEngine\
    ├─ cmd\forgeEngineCmdList.ps1   fe- 调试指令集（cd 自动加载）
    ├─ config\                      cmake\(ForgeShader/中间目录) + tool\(构建期小工具) + vcpkg\(triplet + port 9)
    ├─ src\code\vk\                 Vulkan 渲染层
    ├─ src\code\forge\              世界/游戏层（Plate/Chunk/Storage）
    ├─ src\assets\                  shader_src(GLSL 入库)/shader(spv 忽略)/image/model/music/font
    ├─ docs\                        对外文档 + chatbox-docs\（本目录，AI 协作）
    └─ build\                       vs\ · vcpkg_installed\ · ninja\

## 快速开始（新机器）

前置：VS2026（18.x，生成器 `Visual Studio 18 2026` + 工具集 v145）+ CMake>=4.2（用 VS2026 自带的 4.3.1 即可）+ Vulkan SDK(VULKAN_SDK) + vcpkg(VCPKG_ROOT)

> 回退（VS2022 保留作兜底）：生成器改回 `Visual Studio 17 2022` + `VCPKG_VISUAL_STUDIO_PATH=<VS2022路径>` + `VCPKG_PLATFORM_TOOLSET=v143` + 删 `build\vcpkg_installed` 重建（binary cache 秒回）。
> **exe 与 vcpkg 依赖必须同工具链**——混链会报 LNK2019 `__std_unique_4`。

    cmake --preset vs             # vcpkg 自动装依赖（含间接 29 包，首次 5-30 分钟）+ 生成 .sln
    cmake --build --preset release
    .\build\vs\bin\output\x64\Release\ForgeEngine.exe

> 日常迭代可用 RelWithDebInfo 配置（/Od /Zi 带 PDB 可断点，编译快、无 STL 检查），见 02_构建体系。

| 查看 | fe-config（含 chatbox-docs）· fe-config-k · fe-ports · fe-st · fe-show |
| 提交 | fe-done "msg" · fe-push |
| 清理工具 | fe-clean · fe-clean-ktx · fe-code |
| 知识库 | `docs\chatbox-docs\`（01~08）即本机 AI 知识库，改动直接生效；规范本体在 Obsidian 库（预授权同步）|

## 约定

- 术语保留源码名（Chunk/Plate/lockInfo）+ 中文说明；代码/文档中文
- 代码 UTF-8 无 BOM；.ps1 带 BOM；bat 用 ANSI/GBK
- 引擎名 ForgeEngine / fe-；游戏层保留 Forge
