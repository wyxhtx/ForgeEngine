## 根路径与构建产物位

    E:\code\graphicsAPI\vulkan\ForgeEngine    项目根（F5 工作目录=根，资源用相对路径 src\assets\...）

## assets 六目录状态

| 目录 | 内容 | 入库 | 说明 |
|---|---|---|---|
| shader_src\ | GLSL（.vert/.frag）| ✅ | 源，改它 → 构建重编 spv |
| shader\ | spv | ❌ 忽略 | 产物，每机现编（fileInfo 加载这里）|
| image\ | ktx2 | ✅ | 运行加载的成品纹理 |
| image_src\ | png/jpeg + 转换 bat | ✅ | 源图，改后需跑 bat 转 ktx2 |
| model\ | gltf/bin | ✅ | |
| music\ | wav | ✅ | |

## storage 与运行数据

    storage\chunk\full|delta\*.dat   运行时区块存档（.gitignore 忽略；删了会重新生成）
    region 循环 3x3x3、region 边长 32、thresholdSize 切换 full/delta

## 路径相关注意

1. 资源路径全部相对项目根（F5 工作目录已设为根），**代码里勿写绝对路径**
2. spv 缺失时运行会报"找不到"——先 fe-br 确保 shader\ 生成齐全
3. 新增 spv 管线时：ForgeShader.cmake 规则 + VkInfo.h fileInfo 变量 **两处命名必须一致**（留意 uiText→uitext 这类大小写细节）
4. image_src 改图流程：改 png/jpeg → 跑 png_to_ktx2.bat → 得到 image\ 新 ktx2
