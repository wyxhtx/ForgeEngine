# ForgeEngine 总览

> AI 协作知识库入口（docs\ai_docs\）。用途：让 AI 快速了解项目全貌后进入任务。
> 阅读顺序：本文件 → 按任务查 02-07。

## 一句话定位

ForgeEngine 是无限体素世界 3D 沙盒游戏引擎（C++20 + Vulkan）。
命名：**ForgeEngine = 引擎**（工程/exe/脚本前缀 fe-）；**Forge = 引擎下的游戏**（游戏层 src\code\forge、进程互斥名）。

## 技术栈

| 领域 | 选型 | 要点 |
|---|---|---|
| 语言 | C++20 MSVC | 单 TU：Main.cpp 内含全部实现 |
| 图形 | Vulkan 1.4 | VK_EXT_MESH_SHADER + VK_KHR_swapchain |
| 依赖 | vcpkg manifest | vcpkg.json 12 库 + config\vcpkg\ overlay |
| 构建 | CMake | vs 预设(.sln) / ninja 预设(命令行) |
| 库 | GLFW/glm/tinygltf/KTX2/FastNoise2/OpenAL+ALUT | 全静态链接 |

## 目录（一级）

    ForgeEngine\
    ├─ cmd\forgeEngineCmdList.ps1   fe- 调试指令集（cd 自动加载）
    ├─ config\                      cmake\ForgeShader + vcpkg\triplet + port(8)
    ├─ src\code\vk\                 Vulkan 渲染层
    ├─ src\code\forge\              世界/游戏层（Plate/Chunk/Storage）
    ├─ src\assets\                  shader_src(GLSL 入库)/shader(spv 忽略)/image/model/music
    ├─ docs\                        对外文档 + ai_docs\（本目录，AI 协作）
    └─ build\                       vs\ · vcpkg_installed\ · ninja\

## 快速开始（新机器）

前置：VS2022 + CMake>=3.25 + Vulkan SDK(VULKAN_SDK) + vcpkg(VCPKG_ROOT)

    cmake --preset vs             # vcpkg 自动装 22 依赖（首次 5-30 分钟）+ 生成 .sln
    cmake --build --preset release
    .\build\vs\bin\output\x64\Release\ForgeEngine.exe

## 调试指令（fe- = ForgeEngine）

| 组 | 指令 |
|---|---|
| 构建运行 | fe-br（常用）· fe-build(-debug) · fe-run(-debug) |
| 查看 | fe-config（含 ai_docs）· fe-config-k · fe-ports · fe-st · fe-show |
| 提交 | fe-done "msg" · fe-push |
| 清理工具 | fe-clean · fe-clean-ktx · fe-code |

> fe-config 输出长时可 fe-config | Select-String '===== docs\\ai_docs' 只看清单。
