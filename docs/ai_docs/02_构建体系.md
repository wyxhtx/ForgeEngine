# ForgeEngine 构建体系（AI 版）

> 用途：改 CMake/vcpkg/依赖/triplet 前先读。讲"做了什么、为什么"，不是配置原文。

## 配置链总览

    vcpkg.json（依赖清单 12 库）
      ↓ manifest 模式（toolchain 自动触发）
    vcpkg（下载+锁版本+编译+安装到 build\vcpkg_installed）
      ↓
    CMakePresets.json（vs/ninja 两预设，含 triplet/overlay 指向）
      ↓ cmake --preset vs
    CMakeLists.txt（7 区块：库查找→主程序→显示分组）
      ↓ VS 生成器
    build\vs\ForgeEngine.sln + vcxproj

## CMakeLists 7 区块

1. MSVC 全局：/utf-8 /W3（源码按 UTF-8 编译，防中文注释乱码）
2. Vulkan SDK：find_package(Vulkan) + glslangValidator（缺失即终止）
3. 官方包：glfw3/glm/VMA/Ktx/OpenAL/ALUT 用 find_package；tinygltf header-only 官方无 config → find_path 封装
4. 自定义库：kmeans/fastnoise2/forgeengine-stb-font → find_path/find_library 手工目标
5. 主程序：单 TU（Main.cpp）+ UNICODE//bigobj/非Debug撤_DEBUG
6. 调试工作目录：F5 工作目录=项目根
7. 着色器：include ForgeShader.cmake → 22 条 GLSL→spv 规则，先于主程序

附注：
- CMAKE_CONFIGURATION_TYPES "Debug;Release"：去掉 MinSizeRel/RelWithDebInfo
- 显示分组：GLOB+source_group 挂 cmd/config/docs(含ai_docs)/assets/code（纯显示不编译）

## triplet（x64-windows-static-forgeengine.cmake）

vcpkg 编译 22 依赖库的规格：

| 行 | 作用 |
|---|---|
| ARCHITECTURE x64 | 只编 x64 库 |
| CRT_LINKAGE static | CRT 静态(/MT)，不依赖 msvcp*.dll |
| LIBRARY_LINKAGE static | 库静态 .lib（无 DLL）→ 全静态 |
| C/CXX_FLAGS_DEBUG IDL=1 | Debug 编库 STL 级别=1，配 Main.h 防 LNK2038 |

注意：triplet 内容改动 → 包 ABI 变 → vcpkg 全量重建（一次性，跑完即稳）。

## 依赖三分类

| 类 | 数量 | 锁定 | 位置 |
|---|---|---|---|
| 官方 | 9 | builtin-baseline | vcpkg 内置 |
| 纯自定义 | 6 目录（aarand/subpar/sanisizer/kmeans/fastnoise2/forgeengine-stb-font）| REF commit | config\vcpkg\port\ |
| 覆盖官方 | 2（ktx/tinygltf）| baseline+overlay 修正 | config\vcpkg\port\ |

实际依赖 12：9 官方 + 3 自定义（kmeans 的 3 依赖为间接，自动递归）。

## 常见问答（结论前置）

- 改 GLSL？→ 改 shader_src，fe-br 增量重编对应 spv
- 换官方库版本？→ 改 builtin-baseline → cmake --preset vs
- 升级自定义库？→ 改 portfile REF（新 commit SHA）→ cmake --preset vs
- 加库？→ vcpkg.json 一行 / 新建端口 2 文件
- 全静态意义？→ exe 单文件分发、不依赖运行库 DLL
- spv 不入库？→ .gitignore shader\，每机现编（编译器匹配）
- vcpkg 输出乱码？→ UTF-8 被 VS 按 GBK 显示，显示层无害
- 依赖为何重建？→ triplet/portfile/baseline 变 → ABI 变 → 一次性重装
