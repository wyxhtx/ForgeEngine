# 自定义端口说明（config\vcpkg\port）

| 端口 | 版本 | 类型 | 作用 | 依赖 |
|---|---|---|---|---|
| aarand | 1.1.0 | header-only | 随机数 | — |
| sanisizer | 0.2.0 | header-only | 数据清洗/过滤 | — |
| subpar | 0.5.0 | header-only | 子进程管理 | — |
| kmeans | 1.0.0 | header-only | 空间聚类（区块并行分区） | aarand, sanisizer, subpar |
| fastnoise2 | 1.1.1 | 静态库 | 噪音生成（FastNoise2 + FastSIMD） | — |
| tinygltf | 3.0.0 | header-only | glTF 模型加载 | nlohmann-json, stb |
| ktx | 4.4.2 | 静态库 | KTX2 纹理（vulkan feature） | zstd, opengl-registry |
| freetype | 2.13.3 | 静态库 | 字体轮廓解析（MSDF 文本栈，overlay 补丁） | brotli, bzip2, libpng, zlib |
| msdf-atlas-gen | 1.3 | 静态库 | MSDF 图集生成（外链官方 msdfgen） | msdfgen[extensions], freetype |

> 注：msdfgen 走官方 port（非 overlay，不入本表），vcpkg.json 直列 `default-features:false + features:extensions`。
> ktx / tinygltf / freetype = 覆盖官方（overlay 修正上游 port）；其余 = 纯自定义（REF 锁 commit）。
