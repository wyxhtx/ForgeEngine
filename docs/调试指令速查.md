# 调试指令速查

由 cmd\.forge.ps1 提供，cd 进项目自动加载，离开自动卸载。

| 指令 | 作用 |
|---|---|
| f-build / f-build-debug | Release / Debug 构建 |
| f-run / f-run-debug | 运行 Release / Debug |
| f-br | 构建 + 运行 |
| f-config / f-config-k | 配置速览 / 只看 ktx |
| f-ports | 已装端口列表 |
| f-st / f-show | git 状态 / diff |
| f-done "msg" | 一键提交 |
| f-push / f-clean / f-clean-ktx / f-code | 推送 / 清理 / ktx残留 / 打开 VS Code |
