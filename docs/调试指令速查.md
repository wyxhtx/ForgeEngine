# 调试指令速查

由 cmd\forgeengine.ps1 提供，cd 进项目自动加载，离开自动卸载。

| 指令 | 作用 |
|---|---|
| fe-build / fe-build-debug | Release / Debug 构建 |
| fe-run / fe-run-debug | 运行 Release / Debug |
| fe-br | 构建 + 运行 |
| fe-config / fe-config-k | 配置速览 / 只看 ktx |
| fe-ports | 已装端口列表 |
| fe-st / fe-show | git 状态 / diff |
| fe-done "msg" | 一键提交 |
| fe-push / fe-clean / fe-clean-ktx / fe-code | 推送 / 清理 / ktx残留 / 打开 VS Code |
