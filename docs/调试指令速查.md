# 调试指令速查

## 构建 / 运行（日常三件套）

| 指令 | 作用 |
|---|---|
| `fe-br` | **构建 + 运行**（最常用）|
| `fe-build` / `fe-build-debug` | 构建 Release / Debug |
| `fe-run` / `fe-run-debug` | 运行 Release / Debug 的 exe |

## 查看（配置 / 状态）

| 指令 | 作用 |
|---|---|
| `fe-config` | 配置速览（全部 34 个配置文件，带行号）|
| `fe-config-k` | 只看 ktx 端口相关（8 个文件）|
| `fe-ports` | 已安装 vcpkg 端口列表 |
| `fe-st` | git 状态 + 最近 5 条提交 |
| `fe-show` | 本次改动 diff（统计 + 详情）|

## 提交 / 推送

| 指令 | 作用 |
|---|---|
| `fe-done "msg"` | 一键提交（git add -A + commit）|
| `fe-push` | 推送到远端 |

## 清理

| 指令 | 作用 |
|---|---|
| `fe-clean` | 清 build\vs（保留 vcpkg_installed）|
| `fe-clean-ktx` | 清 ktx 构建残留（vcpkg 缓存）|

## 工具

| 指令 | 作用 |
|---|---|
| `fe-code` | VS Code 打开工程（无 code 则开资源管理器）|
